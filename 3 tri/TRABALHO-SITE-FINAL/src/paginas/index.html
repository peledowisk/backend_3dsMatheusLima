Aviso de privacidade

Esta versão guarda seu e-mail, nome de jogador, senha protegida por hash, avaliações, listas, leituras e comentários em um arquivo local do servidor. Os dados são usados para manter sua conta e as funcionalidades da comunidade.

Você pode excluir sua conta e os dados associados pelo seu perfil. Este protótipo ainda não possui fluxo de consentimento para newsletter, login social, HTTPS configurado ou backups automáticos. Não use dados reais nesta demonstração.
